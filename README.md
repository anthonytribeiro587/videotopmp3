# Video → MP3

App Next.js que converte arquivos de vídeo/áudio locais para MP3 diretamente no navegador usando FFmpeg.wasm.

## Rodar localmente

```bash
npm install
npm run dev
```

Abra http://localhost:3000.

## Build

```bash
npm run build
npm start
```

## Observação

O app não extrai nem baixa mídia de URLs do YouTube. Use apenas arquivos que você possui ou tem autorização para converter.
